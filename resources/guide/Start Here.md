# Start Here

Welcome to **Holocron**. Your notes are plain `.md` files in this folder — open them in any app, sync them with OneDrive, Dropbox or Git, and they'll always be yours.

This note shows what Holocron can do. Click into any line to see the markdown behind it, then delete this note (and [[Linked Note]]) whenever you like.

> [!tip] Three shortcuts to remember
> - **Ctrl+O** — jump to any note, or create one
> - **Ctrl+Shift+P** — the command palette: every command, searchable
> - **Ctrl+Shift+D** — today's daily note

## Writing

Type markdown and it renders as you go: **bold**, *italic*, ~~strikethrough~~, ==highlight== and `inline code`. The formatting bar above has buttons for all of it, and the **?** button on its right is a cheat sheet.

- Lists continue when you press Enter
- [ ] Tasks too — click the box to tick one
- [x] Like this

## Linking

Type `[[` to link to another note: [[Linked Note]]. Hold **Ctrl** over that link to preview it without leaving this page. Links stay correct when you rename or move notes.

Put `!` in front to embed a note, or just one of its sections:

## Tables

| Shortcut              | What it does                   |
| --------------------- | ------------------------------ |
| Tab                   | Next cell                      |
| Enter                 | Next row (adds one at the end) |
| Alt+Shift+Arrows      | Move a row or column           |
| Ctrl+Alt+Shift+Arrows | Insert a row or column         |

Hover the table for menus on each column and row. Paste cells from Excel and they arrive as a table.

## Ways to view a note

- **Ctrl+Shift+E** — reading view: rendered and read-only
- **Ctrl+Alt+E** — source mode: the raw markdown
- **Ctrl+Alt+F** — focus mode: just you and the paragraph you're writing

## Callouts & folding

> [!note]- Click the title to fold this callout
> Callouts come in note, tip, warning, danger and more. Add `-` after the type to make one start folded.
